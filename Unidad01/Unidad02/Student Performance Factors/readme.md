# Student Performance Factors

## Acerca del conjunto de datos

Este conjunto de datos contiene información sobre diferentes factores que pueden influir en el rendimiento académico de los estudiantes. Incluye datos relacionados con las horas de estudio, la asistencia a clases, las horas de sueño, la motivación, el apoyo de los padres y los recursos disponibles para estudiar.

La base de datos cuenta con **6,607 registros y 20 columnas**, en las que se incluyen datos numéricos y categorías con información sobre las condiciones de los estudiantes.

## Objetivo

El objetivo de este conjunto de datos es analizar qué factores pueden estar relacionados con las calificaciones de los estudiantes. Con esta información se pueden realizar gráficas, comparaciones y análisis estadísticos para conocer cómo influyen los hábitos de estudio, la asistencia y otros aspectos en los resultados de los exámenes.

## Descripción de las variables

| Variable | Descripción |
|---|---|
| `Hours_Studied` | Horas dedicadas al estudio. |
| `Attendance` | Porcentaje de asistencia a clases. |
| `Parental_Involvement` | Nivel de participación de los padres. |
| `Access_to_Resources` | Acceso a materiales y recursos educativos. |
| `Extracurricular_Activities` | Participación en actividades extracurriculares. |
| `Sleep_Hours` | Horas de sueño. |
| `Previous_Scores` | Calificaciones anteriores. |
| `Motivation_Level` | Nivel de motivación del estudiante. |
| `Internet_Access` | Disponibilidad de acceso a internet. |
| `Tutoring_Sessions` | Número de sesiones de tutoría. |
| `Family_Income` | Nivel de ingresos familiares. |
| `Teacher_Quality` | Calidad de los docentes según los datos. |
| `School_Type` | Tipo de escuela, pública o privada. |
| `Peer_Influence` | Influencia de los compañeros. |
| `Physical_Activity` | Actividad física del estudiante. |
| `Learning_Disabilities` | Indica si se registran dificultades de aprendizaje. |
| `Parental_Education_Level` | Nivel educativo de los padres. |
| `Distance_from_Home` | Distancia entre el hogar y la escuela. |
| `Gender` | Género registrado del estudiante. |
| `Exam_Score` | Calificación obtenida en el examen. |

## Posibles análisis

Con esta base de datos se pueden realizar diferentes análisis, por ejemplo:

- Comparar las horas de estudio con las calificaciones de los exámenes.
- Analizar si la asistencia a clases está relacionada con mejores resultados.
- Observar la relación entre las horas de sueño y el rendimiento académico.
- Comparar las calificaciones según el nivel de motivación.
- Investigar si las tutorías y el apoyo familiar están relacionados con el desempeño escolar.

## Conclusión

Esta base de datos es útil para practicar ciencia de datos y estadística, ya que permite explorar diferentes situaciones que pueden influir en el rendimiento académico. A través de su análisis se pueden identificar relaciones entre los hábitos de los estudiantes y sus calificaciones, aunque es importante recordar que una relación entre variables no significa necesariamente que una sea la causa de la otra.
