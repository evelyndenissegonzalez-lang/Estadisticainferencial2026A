# Dataset de Rutinas y Métricas de Fitness

Este dataset proporciona una descripción detallada de las **rutinas de ejercicio, características físicas y métricas de rendimiento de los miembros de un gimnasio**. Contiene **973 muestras** de datos, incluyendo indicadores clave como la frecuencia cardíaca, las calorías quemadas y la duración del entrenamiento.

Cada registro también incluye información demográfica y niveles de experiencia, lo que permite realizar un análisis completo de los patrones de ejercicio, la progresión de los atletas y las tendencias relacionadas con la condición física.

## Características principales

| Variable | Descripción |
|---|---|
| **Age** | Edad del miembro del gimnasio. |
| **Gender** | Género del miembro (Masculino o Femenino). |
| **Weight (kg)** | Peso del miembro en kilogramos. |
| **Height (m)** | Altura del miembro en metros. |
| **Max_BPM** | Frecuencia cardíaca máxima durante las sesiones de entrenamiento, medida en latidos por minuto. |
| **Avg_BPM** | Frecuencia cardíaca promedio durante las sesiones de entrenamiento. |
| **Resting_BPM** | Frecuencia cardíaca en reposo antes de comenzar el entrenamiento. |
| **Session_Duration (hours)** | Duración de cada sesión de entrenamiento en horas. |
| **Calories_Burned** | Total de calorías quemadas durante cada sesión. |
| **Workout_Type** | Tipo de entrenamiento realizado, como Cardio, Strength, Yoga o HIIT. |
| **Fat_Percentage** | Porcentaje de grasa corporal del miembro. |
| **Water_Intake (liters)** | Cantidad diaria de agua consumida durante los entrenamientos, medida en litros. |
| **Workout_Frequency (days/week)** | Número de sesiones de entrenamiento realizadas por semana. |
| **Experience_Level** | Nivel de experiencia del miembro: principiante (1), intermedio (2) y experto (3). |
| **BMI** | Índice de Masa Corporal, calculado a partir del peso y la altura. |

## Aplicaciones del dataset

Este conjunto de datos es adecuado para **científicos de datos, investigadores de salud y personas interesadas en el fitness**, ya que permite estudiar diferentes aspectos relacionados con la actividad física.

Entre sus posibles aplicaciones se encuentran:

- Analizar los **hábitos de ejercicio** de los miembros.
- Estudiar la relación entre la **duración del entrenamiento y las calorías quemadas**.
- Analizar la relación entre la **frecuencia cardíaca y la intensidad del ejercicio**.
- Comparar diferentes **tipos de entrenamiento**.
- Estudiar la **progresión según el nivel de experiencia**.
- Analizar la relación entre características físicas como **peso, altura, grasa corporal y BMI**.
- Identificar patrones relacionados con el **rendimiento y la condición física**.
